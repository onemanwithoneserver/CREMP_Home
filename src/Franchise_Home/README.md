# Content & Media Guidelines: Franchise_Home

This document establishes the official content, typography, character/word count, and media specifications for dynamic backend data across all sections of **Franchise_Home** and **Franchise_Home_01**.

Adhering to these minimum, maximum, and recommended boundaries guarantees optimal visual symmetry, responsive layouts across desktop and mobile, and fast page performance.

### Core Technical Best Practices
- **Format Delivery:** Always serve images in modern `.webp` with `.jpg` fallbacks.
- **Image Compression:** Compress all static images to be under 350KB to maintain sub-second First Contentful Paint (FCP).
- **Consistent Symmetry:** Card grids (Why Choose Us, Models, Support Pillars) depend on uniform text lengths. Aim for the **Recommended** values to avoid broken vertical alignments.
