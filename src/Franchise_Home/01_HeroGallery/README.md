# Franchise Hero Section - Content Requirements

When providing dynamic data from the backend for the Hero section and "Why Choose Us" cards, it is recommended to adhere to the following text length guidelines. This ensures the UI remains balanced and prevents text overflow or awkward spacing.

### Content Length Guidelines

| Section / Element | Recommended Word Count | Recommended Character Count | Description |
| :--- | :--- | :--- | :--- |
| **Main Hero Description** (Top Left) | ~40 - 50 words | ~250 - 300 characters | The primary introductory paragraph. It needs enough text to balance the media gallery on the right, but should be concise enough not to push content down. |
| **Why Choose Us - Card 1** | ~20 - 25 words | ~140 - 170 characters | Text for the first feature card (e.g., Profitable model). |
| **Why Choose Us - Card 2** | ~20 - 25 words | ~140 - 170 characters | Text for the second feature card (e.g., Operational support). |
| **Why Choose Us - Card 3** | ~20 - 25 words | ~140 - 170 characters | Text for the third feature card (e.g., Quality standards). |
| **Why Choose Us - Card 4** | ~20 - 25 words | ~140 - 170 characters | Text for the fourth feature card (e.g., Brand recognition). |

### Important UI Considerations:
- **Card Symmetry:** For the four "Why Choose Us" cards, it is highly recommended to keep the text lengths **consistent across all four cards**. Having one card with 10 words and another with 40 words will break the symmetrical height of the row. Aim for 20-25 words for each point.
- **Responsive Design:** These limits ensure that the text fits well across standard desktop widths down to mobile breakpoints without overflowing containers or causing layout shifts.
